SchemaWhy

Paste a JSON Schema (draft 2020-12) and a JSON document. Every failure comes with its path, the keyword that caused it, and a plain reason.
Covers the validation keywords: type, enum, const, number, string, array and object limits, properties, patternProperties, additionalProperties, items, allOf, anyOf, oneOf, not, if/then/else. Not covered: $ref, $defs, contains, prefixItems, dependent*, unevaluated*, and format (which is only an annotation by default). Patterns use JavaScript regex syntax, which can differ from other languages. Runs in your browser; nothing is uploaded.
Part of the app factory. Source: GitHub.
