5.0 is a valid integer. [1, 1.0] is not unique. oneOf [number, integer] rejects 3 because both match.

What it does

  • Validates a JSON document against a JSON Schema (draft 2020-12 validation keywords) and lists each failure with its path, keyword and reason.
  • Handles the traps: integer vs 1.0, true vs 1, unanchored patterns, characters vs UTF-16 length, oneOf overlap, if/then/else.
  • Runs in your browser. Nothing is uploaded.

How far to trust it

  • Compared with the Python jsonschema library (Draft 2020-12 validator) on 6000 random schema and instance pairs: same failing paths and keywords. Spec sections 6.1 to 6.5 read directly. No $ref, contains, prefixItems or format.
